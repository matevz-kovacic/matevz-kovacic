# Matevž Kovačič

Managing Director and co-owner of **Inetis Ltd**, software engineer, and researcher building verifier-driven AI systems for difficult optimization, algorithmic search, and systems-engineering problems.

## Selected results

* **Solved the long-standing English perfect 10-square problem**, producing the first proper English 10-square. For the history of the problem, see [Wikipedia](https://en.wikipedia.org/wiki/Word_square#Order_10_squares). [Code and publication](https://github.com/matevz-kovacic/word-square)
* **Established new best-known results on two circle-packing benchmarks**, improving on results reported by Google DeepMind’s AlphaEvolve: 32 variable-radius circles in a unit square and 21 variable-radius circles in a perimeter-4 rectangle. [Verified Active Model results](https://github.com/matevz-kovacic/active-model)
* Produced additional best-known numerical results in circle packing and spherical codes, as well as a large-scale AC optimal-power-flow result accepted into MINLPLib.
* Developing **Active Model**, a verifier-driven system for cold-start search over difficult computational and software-engineering problems.
